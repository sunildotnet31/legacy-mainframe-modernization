# Db2 Data Model

The simplified model uses fixed-length CHAR and numeric columns only. Every column is NOT NULL. DATE, TIME, TIMESTAMP and VARCHAR columns have been removed.

- **CUSTOMER**: CUSTOMER_ID, FIRST_NAME, LAST_NAME, EMAIL_ADDRESS, PHONE_NUMBER, KYC_STATUS, CUSTOMER_STATUS
- **BRANCH**: BRANCH_ID, BRANCH_NAME, IFSC_CODE, CITY, BRANCH_STATUS
- **PRODUCT**: PRODUCT_ID, PRODUCT_NAME, PRODUCT_TYPE, CURRENCY_CODE, MIN_BALANCE, PRODUCT_STATUS
- **ACCOUNT**: ACCOUNT_ID, CUSTOMER_ID, BRANCH_ID, PRODUCT_ID, ACCOUNT_STATUS, LEDGER_BALANCE, AVAILABLE_BALANCE, TXN_LIMIT
- **ACCOUNT_TXN**: TRANSACTION_ID, ACCOUNT_ID, TRANSACTION_TYPE, DEBIT_CREDIT, AMOUNT, CURRENCY_CODE, CHANNEL_CODE, REFERENCE_NO, TXN_STATUS
- **BENEFICIARY**: BENEFICIARY_ID, CUSTOMER_ID, BENEFICIARY_NAME, BANK_IFSC, BANK_ACCOUNT_NO, BENEFICIARY_STATUS
- **LOAN**: LOAN_ID, CUSTOMER_ID, LOAN_TYPE, PRINCIPAL_AMOUNT, OUTSTANDING_AMOUNT, INTEREST_RATE, LOAN_STATUS
- **LOAN_PAYMENT**: PAYMENT_ID, LOAN_ID, PAYMENT_AMOUNT, PRINCIPAL_PAID, INTEREST_PAID, PAYMENT_STATUS
- **AUDIT_LOG**: AUDIT_ID, USER_ID, PROGRAM_ID, EVENT_TYPE, ENTITY_KEY, EVENT_STATUS, EVENT_TEXT
- **NOTIFICATION**: NOTIFICATION_ID, CUSTOMER_ID, CHANNEL_CODE, DESTINATION, MESSAGE_TEXT, DELIVERY_STATUS

Relationships:
- CUSTOMER 1:N ACCOUNT
- BRANCH 1:N ACCOUNT
- PRODUCT 1:N ACCOUNT
- ACCOUNT 1:N ACCOUNT_TXN
- CUSTOMER 1:N BENEFICIARY
- CUSTOMER 1:N LOAN
- LOAN 1:N LOAN_PAYMENT
- CUSTOMER 1:N NOTIFICATION
