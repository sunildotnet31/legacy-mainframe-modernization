# Legacy Mainframe Modernization

Sample repository for AI-powered legacy IT modernization.

## Repository Structure

- cobol/programs - 50 COBOL sample programs
- cobol/copybooks - Shared COBOL copybooks
- db2/ddl - 10 Db2 table definitions
- db2/dclgen - DCLGEN-style members
- jcl/batch - 5 sample batch jobs
- docs - Project documentation

## Purpose

This repository supports experimentation with:

- Generative AI
- Retrieval-Augmented Generation (RAG)
- Knowledge Graphs using Neo4j
- Legacy code analysis
- Mainframe modernization

Note: These are educational sample assets, not production-ready or compiler-certified programs.
